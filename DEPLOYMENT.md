# Deployment Guide

## Overview

This guide covers deploying the ELK Stack with Logstash unified flow collectors for NetFlow and sFlow monitoring.

## Requirements

- Docker & Docker Compose on all servers
- Network connectivity between collectors (backends) and Elasticsearch (frontend)
- TLS certificates (auto-generated by deploy.sh)

## Architecture

```
Frontend (Kibana + Elasticsearch)
├── Elasticsearch: https://<FRONTEND_IP>:9200
└── Kibana: http://<FRONTEND_IP>:5601

Backends (Logstash Collectors)
├── Backend N1: UDP 2050 (NetFlow), 6343 (sFlow)
└── Backend N2: UDP 2050 (NetFlow), 6343 (sFlow)

Index Pattern: logstash-flow-*
```

Each Logstash collector can receive both NetFlow and sFlow simultaneously.

## Quick Start

### Step 1: Deploy Frontend

```bash
# Clone and configure
git clone https://github.com/your-org/custom-elk-stack.git
cd custom-elk-stack

# Generate configuration
./deploy.sh --generate

# Edit config
nano deploy.conf
```

Required settings in `deploy.conf`:
```bash
CLUSTER_NAME="flow-monitoring-cluster"
STACK_VERSION="8.16.0"
ELASTIC_PASSWORD="your-secure-password"
FRONTEND_IP="10.4.4.87"
ES_PORT="9200"
KIBANA_PORT="5601"
ELASTICSEARCH_HOST="10.4.4.87:9200"
```

Deploy:
```bash
./deploy.sh --frontend
```

### Step 2: Set Up Elasticsearch

```bash
# Create ILM policy and index template
./logstash-migration/setup-elasticsearch.sh
```

This creates:
- ILM policy `flow-data-3-day`
- Index template `logstash-flow`
- Rollover alias `logstash-flow`

### Step 3: Deploy Logstash Collectors

**On each backend server:**

```bash
# Copy files to backend
mkdir -p /opt/logstash-flow/
cd /opt/logstash-flow/

# Copy from frontend
cp /path/to/custom-elk-stack/logstash-migration/*.conf .
cp /path/to/custom-elk-stack/logstash-migration/*.json .
cp /path/to/custom-elk-stack/logstash-migration/*.yml .
cp /path/to/custom-elk-stack/logstash-migration/Dockerfile .

# Create environment file
cat > .env << EOF
ELASTICSEARCH_HOST=10.4.4.87:9200
ELASTIC_PASSWORD=your-password-here
EOF

# Start Logstash
docker compose up -d --build

# Verify startup
sleep 10
docker logs logstash-flow --tail 50
```

**Verify collector is running:**
```bash
# Check container
docker ps | grep logstash-flow

# Check API (on backend)
curl http://localhost:9600/_node/stats

# Check ports
ss -uln | grep -E "(2050|6343)"
```

### Step 4: Import Dashboards

```bash
# From frontend
./deploy.sh --import

# Or manually:
curl -k -u elastic:password \
  -X POST "https://<FRONTEND_IP>:5601/api/saved_objects/_import?overwrite=true" \
  -H "kbn-xsrf: true" \
  --form file=@logstash-migration/dashboards/unified-flow-dashboards.ndjson
```

### Step 5: Verify Deployment

```bash
./deploy.sh --verify
```

Expected output:
```
Cluster status: GREEN
Kibana: Available
Flow indices: logstash-flow-YYYY.MM.dd
Document count: >0
```

## Configuration Files

### Logstash Configuration

**File:** `logstash-migration/logstash.conf`

```ruby
input {
  # NetFlow v9 from Juniper devices
  udp {
    port => 2050
    codec => netflow { versions => [9] }
    add_field => { "[@metadata][input_type]" => "netflow" }
  }

  # sFlow v5 from Cisco Nexus
  udp {
    port => 6343
    codec => sflow
    add_field => { "[@metadata][input_type]" => "sflow" }
  }
}

filter {
  # Extract host.ip for filtering
  # Map fields to ECS schema
  # Calculate sampling rates
  # Detect flow locality
}

output {
  elasticsearch {
    hosts => ["https://10.4.4.87:9200"]
    user => "elastic"
    password => "telehouse"
    ssl => true
    ssl_certificate_verification => false
    index => "logstash-flow-%{+YYYY.MM.dd}"
    template => "/usr/share/logstash/templates/flow-template.json"
  }
}
```

### Docker Compose

**File:** `logstash-migration/docker-compose.yml`

```yaml
version: '3'
services:
  logstash:
    build: .
    image: logstash-flow:latest
    container_name: logstash-flow
    restart: unless-stopped
    network_mode: host
    volumes:
      - ./logstash.conf:/usr/share/logstash/pipeline/logstash.conf:ro
      - ./flow-template.json:/usr/share/logstash/templates/flow-template.json:ro
    logging:
      driver: json-file
      options:
        max-size: "100m"
        max-file: "3"
```

## Network Device Configuration

### Cisco Nexus (sFlow)

```cisco
feature sflow
sflow collector-ip <BACKEND_IP> vrf default
sflow collector-port 6343
sflow agent-ip <SWITCH_IP>
sflow sampling-rate 4096
sflow max-sampled-size 128

# Add interfaces to monitor
sflow data-source interface Ethernet1/1
sflow data-source interface port-channel1
```

### Juniper (NetFlow)

```juniper
set services flow-monitoring version 9
set forwarding-options sampling input rate 4096
set forwarding-options sampling family inet output flow-server <BACKEND_IP> port 2050
set forwarding-options sampling family inet output flow-server <BACKEND_IP> version 9
```

## Filtering Data

### By Exporter Device (host.ip)

In Kibana KQL search bar:
```
host.ip: 10.4.4.93
```

### By Source or Destination
```
source.ip: 10.4.4.93
destination.ip: 10.4.4.3
```

### By Protocol
```
network.transport: tcp
```

### Combined Filters
```
host.ip: 10.4.4.93 AND network.transport: tcp AND destination.port: 443
```

See full filtering guide in [docs/logstash/README.md](docs/logstash/README.md).

## Kibana Dashboards

### Available Dashboards

1. **[Unified Flow] Detailed Traffic Analysis**
   - Traffic timeline by device (host.ip)
   - Protocol distribution
   - Top sources/destinations
   - Device breakdown

2. **[Unified Flow] Top-N Analysis**
   - Top sources by bytes/packets
   - Top destinations
   - Top protocols
   - Top ports

3. **[Unified Flow] Conversation Partners**
   - Source-destination pairs
   - Traffic volume
   - Flow counts

### Index Pattern

- **Pattern:** `logstash-flow-*`
- **Time field:** `@timestamp`
- **Refresh:** 15 seconds

## Troubleshooting

### No Data from Devices

```bash
# Check Logstash is listening
ss -uln | grep -E "(2050|6343)"

# Check logs
docker logs logstash-flow --tail 50

# Check network
tcpdump -i any udp port 6343 -n
tcpdump -i any udp port 2050 -n

# Check switch config
show sflow  # Cisco
show configuration | match flow  # Juniper
```

### Dashboard Shows "No Results"

1. Check time range (Last 15 minutes)
2. Verify index pattern: `logstash-flow-*`
3. Check `host.ip` exists in data
4. Try `host.ip: *` to see all devices

### Mapping Errors

```bash
# Delete conflicting indices
curl -k -u elastic:password -X DELETE \
  "https://10.4.4.87:9200/logstash-flow-*"

# Re-run setup
./logstash-migration/setup-elasticsearch.sh

# Restart Logstash
docker compose restart
```

### Collector Connection Issues

```bash
# Test ES connectivity from backend
curl -k -u elastic:password \
  "https://10.4.4.87:9200"

# Check Logstash config
docker exec logstash-flow cat /usr/share/logstash/pipeline/logstash.conf

# Restart collector
docker compose restart logstash-flow
```

## Scaling

### Multiple Collectors

Deploy Logstash on multiple backends:

```
Backend N1: Port 2050 → ES
Backend N2: Port 6343 → ES
Backend N3: Ports 2050,6343 → ES
```

All collectors write to the same `logstash-flow-*` index.

### Load Distribution

Route devices to different collectors:

```
Routers (NetFlow)  → Backend N1:2050
Switches (sFlow)     → Backend N2:6343
Mixed devices        → Backend N3:2050,6343
```

Or for redundancy:
```
All NetFlow devices  → Backend N1:2050 AND Backend N2:2050
All sFlow devices    → Backend N1:6343 AND Backend N2:6343
```

## ILM Policy

**Default:** 3-day retention

| Phase | Action | Duration |
|-------|--------|----------|
| Hot | Rollover | Daily or 50GB |
| Warm | Shrink, Force Merge | After 1 day |
| Delete | Remove index | After 3 days |

Modify in `logstash-migration/setup-elasticsearch.sh`.

## Ports

| Service | Port | Protocol | Direction |
|---------|------|----------|-----------|
| Kibana | 5601 | TCP | Frontend |
| Elasticsearch | 9200 | TCP | Frontend |
| NetFlow | 2050 | UDP | Device → Backend |
| sFlow | 6343 | UDP | Device → Backend |
| Logstash API | 9600 | TCP | Backend localhost |
