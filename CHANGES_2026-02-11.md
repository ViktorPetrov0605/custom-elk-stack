### 2. Unified Network Flow Schema
Created unified Logstash configurations that normalize both NetFlow (Juniper) and sFlow (Cisco) to common fields:

**New Configs:**
- `logstash/logstash-unified-netflow.conf` - Backend N1 (Juniper NetFlow)
- `logstash/logstash-unified-sflow.conf` - Backend N2 (Cisco sFlow)

**Unified Schema Fields:**
- `@timestamp` - Event time
- `device.name` - "juniper-sw" or "cisco-nexus"
- `device.ip` - Source exporter IP
- `source.ip` / `source.port` / `source.as.number`
- `destination.ip` / `destination.port` / `destination.as.number`
- `network.transport` - TCP/UDP/ICMP
- `network.bytes` - **With 4096x sampling multiplier applied**
- `network.packets` - **With 4096x sampling multiplier applied**
- `interface.input` / `interface.output` - SNMP interface IDs
- `sampling.rate` - 4096 for Juniper, 1 for sFlow

### 3. Sampling Multiplier Implementation
- **Juniper NetFlow**: Uses 1/4096 sampling
- **Logstash Ruby filter** multiplies bytes/packets by 4096:
  ```ruby
  event.set('[network][bytes]', event.get('[netflow][in_bytes]').to_i * 4096)
  ```
