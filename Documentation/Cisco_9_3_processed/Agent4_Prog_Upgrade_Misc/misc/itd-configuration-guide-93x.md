## What is ITD?

Intelligent Traffic Director (ITD) provides high-performance, scalable traffic redirection and load balancing for Cisco Nexus 9000 Series switches. Key capabilities include:

- **Hardware-based traffic steering** - Line-rate performance
- **Flexible load balancing** - Multiple algorithms (source IP, destination IP, 5-tuple)
- **Health monitoring** - Automatic failover to healthy nodes
- **Service insertion** - Chain services transparently
- **vPC support** - Redundancy across vPC peers
- **High availability** - Stateful failover capabilities
