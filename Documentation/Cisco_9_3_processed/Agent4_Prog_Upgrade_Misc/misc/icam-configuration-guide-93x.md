## What is iCAM?

iCAM (Intelligent CAM) provides visibility into hardware forwarding table utilization on Cisco Nexus 9000 switches. It enables proactive monitoring of critical hardware resources including:

- TCAM (Ternary Content Addressable Memory) utilization
- Hardware forwarding entries
- ACL resources
- QoS resources
- Other hardware table usage
