## Overview

This document lists the RFCs (Request for Comments) and standards supported by the Cisco Nexus 9000 Series NX-OS Programmability features.

---

## NETCONF RFCs

- RFC 6241 - Network Configuration Protocol (NETCONF)
- RFC 6242 - Using the NETCONF Protocol over Secure Shell (SSH)
- RFC 6243 - With-defaults Capability for NETCONF
- RFC 6244 - Configuration Management with NETCONF
- RFC 5277 - NETCONF Event Notifications
- RFC 8341 - Network Configuration Access Control Model (NACM)

---

## YANG RFCs

- RFC 6020 - YANG - A Data Modeling Language for the Network Configuration Protocol (NETCONF)
- RFC 6021 - Common YANG Data Types
- RFC 6087 - Guidelines for Authors and Reviewers of YANG Data Model Documents
- RFC 8340 - YANG Tree Diagrams
- RFC 8342 - Network Management Datastore Architecture (NMDA)
- RFC 8446 - The Transport Layer Security (TLS) Protocol Version 1.3
