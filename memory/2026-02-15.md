# 2026-02-15 Memory Log

## ElastiFlow sFlow Fix

**Issue:** Cisco Nexus switches (10.4.4.3, 10.4.4.4) were not sending data to Elasticsearch.

**Diagnosis:**
- Backend N2 collector (10.4.4.90) was in "unhealthy" state
- Bootstrap error: `Invalid alias name [elastiflow-flow-ecs-8.0-2.5-rollover]: an index or data stream exists with the same name as the alias`
- Both N1 and N2 had `EF_OUTPUT_ELASTICSEARCH_INDEX_TEMPLATE_ENABLE: "true"`
- N1 created the index/alias first, N2 failed to bootstrap

**Fix Applied:**
1. Set `EF_OUTPUT_ELASTICSEARCH_INDEX_TEMPLATE_ENABLE: "false"` on Backend N2
2. Restarted collector on N2: `docker compose down && docker compose up -d`

**Results:**

|--------|------------|-----------|
| 10.4.4.93 (Juniper) | 107M | 109M |
| 10.4.4.3 (Nexus 1) | 11 | 43,458 |
| 10.4.4.4 (Nexus 2) | 4 | 50,430 |
