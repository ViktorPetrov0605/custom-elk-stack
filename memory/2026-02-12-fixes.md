# Elasticsearch Field Mapping Fix - 2026-02-12

## Problems Found
Dashboards showing errors:
- `Field @timestamp is of the wrong type`
- `network.transport invalid for Terms aggregation`
- `source.ip invalid for Unique Count aggregation`
- `destination.ip invalid for Unique Count aggregation`

## Root Cause
Index `elastiflow-flow-ecs-8.0-2.5-rollover-000001` had wrong field mappings:
- `@timestamp` was `long` instead of `date`
- `source.ip` was `text` instead of `ip`
- `destination.ip` was `text` instead of `ip`
- `network.transport` was `text` instead of `keyword`

## Solution Applied

### 1. Created Override Index Template
```bash
curl -u elastic:telehouse -X PUT "https://10.4.4.87:9200/_index_template/elastiflow-flow-ecs-fix" \
  -H 'Content-Type: application/json' \
  -d '{
    "index_patterns": ["elastiflow-flow-ecs-*"],
    "priority": 1000,
    "template": {
      "mappings": {
        "properties": {
          "@timestamp": {"type": "date"},
          "source.ip": {"type": "ip"},
          "destination.ip": {"type": "ip"},
          "network.transport": {"type": "keyword"}
        }
      },
      "settings": {
        "number_of_shards": 1,
        "number_of_replicas": 0,
        "index.lifecycle.name": "elastiflow"
      }
    }
  }'
```

### 2. Deleted Broken Index
```bash
# Deleted: elastiflow-flow-ecs-8.0-2.5-rollover-000001
curl -u elastic:telehouse -X DELETE "https://10.4.4.87:9200/elastiflow-flow-ecs-8.0-2.5-rollover-000001"
```

### 3. Restarted Collectors
```bash
# Backend N2 (sFlow)
sshpass -p 'T3l3h0us#' ssh telehouse@10.4.4.90 "cd ~/elastiflow && docker compose up -d"

# Backend N1 (NetFlow)  
sshpass -p 'T3l3h0us#' ssh -p 2332 telehouse@10.4.4.21 "cd ~/elastiflow && docker-compose up -d"
```

## Result
New index created with correct mappings:
- `@timestamp`: date ✅
- `source.ip`: ip ✅
- `destination.ip`: ip ✅
- `network.transport`: keyword ✅

Dashboards now work properly:
- Protocol Distribution (Terms aggregation) ✅
- Top Sources (Unique Count) ✅
- Top Destinations (Unique Count) ✅
- Total Bytes/Packets metrics ✅
- Traffic Timeline ✅

## Note
Both collectors use different Docker syntax:
- Backend N2: Uses `docker compose` (space, newer)
- Backend N1: Uses `docker-compose` (hyphen, older v1)
