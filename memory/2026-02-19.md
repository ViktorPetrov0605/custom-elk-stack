## Lessons Learned
- **Type Safety**: Always cast network host fields to String before use in `mutate` filters.
- **NAT Awareness**: Check for infrastructure-level IP translation (Docker/NAT) when relying on peer IPs for device identification.
- **Scaling Logics**: Juniper multipliers (4096x) must be applied specifically to mapped external IPs, not internal gateway IPs.
