## Voice Message Transcription Setup

Successfully set up local speech-to-text transcription using OpenAI Whisper.

### What was done:
1. Created Python virtual environment at `~/.openclaw/whisper-venv`
2. Installed Whisper with CPU-optimized PyTorch
3. Installed ffmpeg (required for audio processing)
4. Created transcription script at `~/.openclaw/scripts/transcribe_voice.sh`
5. Tested with English and Bulgarian voice messages — both work

### Technical details:
- Model: Whisper `base` (151MB)
- Hardware: 6 cores, 8GB RAM — handles transcription in ~2-5 seconds
- Languages supported: 99 total, tested with English and Bulgarian
- For Bulgarian: convert to WAV 16kHz mono first, then use `--language bg`

## Qwen3-TTS Research

Researched Qwen3-TTS (Alibaba's open-source TTS with voice cloning).

**Key findings:**
- Can clone voices from 3-second audio samples
- 10 languages supported (English, Bulgarian not in list)
- Requires CUDA GPU for practical use (CPU too slow)
- Viktor plans to set up CUDA server for this in future

**Documentation sources:**
- GitHub: https://github.com/QwenLM/Qwen3-TTS
